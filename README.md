# Arnav Somani — Portfolio

Personal website for Arnav Somani, an Information Sciences + Data Science student at the University of Illinois Urbana-Champaign.

It's a single static page (`index.html`) with no build step. It uses the UIUC palette and has scroll-reveal sections, an animated experience timeline, project demo videos and a downloadable Android app.

## Publish with GitHub Pages

1. Create a repository named **`somani0503.github.io`**. The site is then served at `https://somani0503.github.io`.
2. Push this folder to the `main` branch.
3. In the repository, go to **Settings → Pages** and set the source to **Deploy from a branch → `main` / root**.

## Editing

| What | Where |
|---|---|
| Text, experience, projects | `index.html` |
| Resume | replace `resume.pdf` and `resume-thumbnail.png` |
| Photo | replace `assets/arnav.jpg` |
| Beyond the Code (acting, modelling, football) | `index.html`, images in `assets/beyond/` |
| Project videos | `assets/video/` |
| Campus Connect APK | `assets/downloads/CampusConnect.apk` |

## Projects featured

- [Crypto Market Simulator](https://github.com/somani0503/crypto-market-simulator): Flask, live Binance prices, regression and Monte Carlo price forecasts
- [CampusConnect](https://github.com/somani0503/campus-connect): Android app (Java and Firebase) for UIUC students
